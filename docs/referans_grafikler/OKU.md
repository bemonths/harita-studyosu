# Görsel referans (grafik ve vaat sahneleri)

Bu klasör `STUDYO_TASK_grafik_sahneleri.md` görevinin görsel referansıdır. Görüntüler Florida'nın gerçek verisiyle, iki prototip betikle (`vaad.py`, `grafikler.py`) üretildi.

- Görüntüler son karelerdir; zamanlamalar prototip betiklerde (`seg(t, başlangıç, bitiş)` çağrıları).
- Prototipler bağımsız matplotlib betikleridir; depodaki sahne sözleşmesine (`engine/scene.py`) uymaz. Görünüm, yerleşim ve zamanlama için referanstır, kod olarak kopyalanmaz.
- Eşleşme: 00_question_board → `question_board`; 00_county_quiz_* → `county_quiz`; 01/02 → `house_bars`; 03 → `line_trend`; 04/05 → `bar_list`; 06 → `ring`; 07 → `thermometer`; 08 → `house_grid`.
